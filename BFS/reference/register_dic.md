# Swiss official commune register: dictionary

The variables of the commune register datasets, in German, French and
Italian.

## Usage

``` r
register_dic
```

## Format

A data frame with 27 rows and 5 columns:

- language:

  Language: "de", "fr" or "it".

- abbreviation:

  Variable name, e.g. "GDENR".

- title:

  Variable label.

- spec:

  Specifications.

- notes:

  General notes.
