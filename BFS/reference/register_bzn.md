# Swiss official commune register: districts

The districts of Switzerland (or comparable administrative entities) on
1 January 2023.

## Usage

``` r
register_bzn
```

## Format

A data frame with 143 rows and 3 columns:

- GDEKT:

  Canton abbreviation, e.g. "ZH".

- GDEBZNR:

  District number.

- GDEBZNA:

  District name.
