# Swiss official commune register: cantons

The 26 cantons of Switzerland.

## Usage

``` r
register_kt
```

## Format

A data frame with 26 rows and 3 columns:

- KTNR:

  Canton number.

- GDEKT:

  Canton abbreviation, e.g. "ZH".

- GDEKTNA:

  Canton name.
