# TreeItemProvider

<https://mui.com/x/api/tree-view/tree-item-provider/>

Provides the context of a tree item when building a custom tree item.

## Usage

``` r
TreeItemProvider(...)
```

## Arguments

- ...:

  Props to pass to the component.

## Value

Object with `shiny.tag` class suitable for use in the UI of a Shiny app.

## Details

- children `node`  
  Default is - The content of the component.

- itemId `string`  
  Default is - The id of the item.

- id `string`  
  Default is - The id attribute of the item.
