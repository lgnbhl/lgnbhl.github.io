# TreeItemCheckbox

Checkbox slot of a tree item, rendered when `checkboxSelection = TRUE`.
Building block for customizing
[`TreeItem()`](https://felixluginbuhl.com/muiTreeView/reference/TreeItem.md).
See <https://mui.com/x/react-tree-view/tree-item-customization/>.

## Usage

``` r
TreeItemCheckbox(...)
```

## Arguments

- ...:

  Props to pass to the component.

## Value

Object with `shiny.tag` class suitable for use in the UI of a Shiny app.
